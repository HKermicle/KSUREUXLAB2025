# KSUREUXLAB2025

This Repository is for the 2025 REU at KSU. The project is advised by Dr. Xie at XLab. 


This projects goal is to Predict Protein and drug binding affinity using ML models, and aims to aid in developmental drug discovery, cutting down on time and cost experimenting with potential compounds. This repository utilizes a Random Forest Model to analyze paired protein ligand interactions and calculate the binding affinity from "low", "Medium", and "high".
